# PROBAT 烘豆溫度記錄器

用手機相機對準 PROBAT 烘豆機的七段 LED 溫度顯示器，即時辨識豆溫、繪製烘焙曲線，結束後匯出 CSV。純前端網頁，無需安裝任何 App。

## 使用方式

1. 用手機瀏覽器開啟本頁（需 HTTPS，GitHub Pages 網址即可）
2. 允許相機權限，將鏡頭對準烘豆機面板
3. 拖曳紅框大致框住「溫度顯示器」一帶——綠色虛線框會自動鎖定實際數字區域
4. 按「開始烘豆」，每 5 秒取樣一次畫出豆溫曲線
5. 按「停止並匯出」下載 CSV 紀錄

### 測試模式

網址加上 `?source=mp4` 會改用倉庫內的 `video.mp4` 示範影片代替相機，
方便在電腦上驗證辨識效果。

## 辨識原理

- 紅色像素過濾（自適應閾值）→ 直欄投影切字 → 七段最大似然解碼
- 自動 ROI：在使用者框內以連通元件分析找出「黑底紅字」的顯示窗，
  排除按鈕與指示燈，並隨畫面晃動追蹤
- 多數決濾波 + 連續性鎖定 + 缺漏百位修復，對抗 LED 掃描閃爍

## 建議

- 手機固定在腳架上，準確率最佳
- 紅框只需大致框住顯示器，不必精準
